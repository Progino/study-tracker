# study-tracker
A tracker where you can input your subjects and than start tracking them with a standard timer or a pomodoro timer.
You can also delte subjects, because they get saved so if you close and then reopen the project the subject will still be there.
You can see the subjects stats, you can choose by seeing everything at one or a single subject at a time.
There is also a calendar that let you see the current date.
To navigate between the option you will have to use the numbers placed before the option you want to choose.

Coding language: c++
Made using: Visual Studio 2026
